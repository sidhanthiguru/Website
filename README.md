# Sidhanthi Guru Yoga Academy — Website

Official website for Sidhanthi Guru Yoga Academy, built with React, Vite, and Firebase.

## Tech Stack

- **React 18** + **React Router 6** — UI and routing
- **Vite 6** — build tooling and dev server
- **Firebase 12** — backend (auth, Firestore, hosting)
- **Motion** + **Lenis** — animations and smooth scrolling
- **Lucide React** / **React Icons** — iconography

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Command          | Description                 |
| ---------------- | --------------------------- |
| `npm run dev`    | Start the Vite dev server   |
| `npm run build`  | Production build            |
| `npm run preview`| Preview the production build|
